# 🎧 KINETIX KX-01 - Interactive 3D Acoustic Product Landing Page

> **Progree Frontend Development Internship - Task 02**  
> A mobile-responsive, Neo-Brutalist Cyber-Acoustic marketing landing page featuring a real-time interactive **Three.js 3D headphone model**, scroll-driven exploded engineering view, and live neural noise-cancellation telemetry.

🔗 **Live Demo:** [View Deployed Site](https://ahmed-ashraf-74.github.io/Progree-task2-kinetix-audio/)

---

## ✨ Key Features

- **Interactive 3D WebGL Stage (`Three.js`):** Full 360° hold-and-drag rotation (mouse & touch supported) with custom studio lighting and dynamic material switching.
- **Scroll-Driven Exploded Architecture:** Smoothly separates the ear-cup housing and telemetry LED rings as the user scrolls through the hardware engineering section.
- **Live Neural ANC Visualizer:** Real-time animated acoustic waveform simulator toggling between active noise cancellation (`-48.4 dB`) and ambient pass-through.
- **Interactive AI Sound Environments (Bento Grid):** Switch between _Studio Isolation_, _Vocal Focus+_, _360° Spatial Cinema_, and _Hyper-Low Latency_ modes to dynamically change the 3D headset's LED accent colors.
- **Chassis Edition Configurator:** Preview _Titanium Slate_, _Anodized Graphite_, and _Arctic Ceramic_ finishes live on the 3D model.
- **Semantic HTML5 & Strict Responsive Layout:** Built with `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`, utilizing CSS Grid, Flexbox, and explicit media queries with zero horizontal overflow.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure & accessibility attributes (`ARIA`)
- **CSS3:** Custom CSS Variables, CSS Grid (Bento Layout), Flexbox, Chamfered `clip-path` geometry, and Responsive Media Queries
- **JavaScript (ES6+):** DOM telemetry engine & interactive state management
- **Three.js (r128):** Procedural 3D headphone geometry, PBR metallic materials, and WebGL rendering
